# Version in English:
# 📊 Power BI – Sales Dashboard for Gatito Petshop

This project was developed based on a real business need from **Gatito Petshop**, which required a Business Intelligence solution to monitor sales and identify growth opportunities. The work covered the entire BI cycle — from understanding the business context to delivering a functional and strategic dashboard.

## What Was Developed

- Built a complete interactive dashboard in Power BI **from scratch**  
- Applied the full **ETL (Extract, Transform, Load)** process:
  - Extraction of raw data provided by Gatito Petshop  
  - Data cleaning and standardization  
  - Data modeling and loading into Power BI  
- Defined key metrics after interviewing the business owner  
- Created calculated measures using **DAX**  
- Designed the layout with a focus on clarity and decision-making

## Tools and Techniques Used

- Power BI Desktop  
- DAX Language  
- Excel (datasets)  
- Data Modeling

## Main Dashboard KPIs

- **Total Revenue**  
- **Average Ticket Size**  
- **Revenue by Category**  
- **Sales by Product**  
- **Performance by Region/Period**

## Insights Generated

- Certain categories showed higher profit margins  
- Specific regions performed better in determined time periods  
- High-volume products were not always the most profitable

## Outcome

The final dashboard provides **Gatito Petshop** with a clear and strategic view of sales, supporting data-driven decision-making.  
The project strengthened practical skills in ETL, DAX, data visualization, and stakeholder communication.

# Versão em Português:
# 📊 Power BI – Dashboard de Vendas para a Gatito Petshop

Este projeto foi desenvolvido com base na necessidade real da **Gatito Petshop**, que buscava uma solução em Business Intelligence para acompanhar suas vendas e identificar oportunidades de crescimento. A entrega envolveu todo o ciclo de BI — desde a compreensão do negócio até a criação de um dashboard funcional e estratégico.

## O que foi desenvolvido

- Construção **do zero** de um dashboard interativo no Power BI  
- Aplicação completa do processo **ETL (Extract, Transform, Load)**:
  - Extração dos dados brutos enviados pela Gatito Petshop  
  - Tratamento e padronização das informações  
  - Modelagem e carregamento no Power BI  
- Definição das métricas após entrevista com a proprietária  
- Criação de medidas em **DAX**  
- Design focado em clareza e tomada de decisão

## Ferramentas e Técnicas Utilizadas

- Power BI Desktop  
- Linguagem DAX  
- Excel (datasets)  
- Modelagem de Dados

## Principais KPIs do Dashboard

- **Faturamento Total**  
- **Ticket Médio**  
- **Receita por Categoria**  
- **Vendas por Produto**  
- **Performance por Região/Período**

## Insights Gerados

- Algumas categorias apresentaram maior margem de faturamento  
- Regiões específicas performam melhor em determinados períodos  
- Produtos com maior volume de venda não são necessariamente os mais lucrativos

## Resultado

O dashboard final oferece à **Gatito Petshop** uma visão clara e estratégica das vendas, facilitando decisões baseadas em dados. 
O projeto consolidou habilidades práticas em ETL, DAX, visualização e comunicação com stakeholders.
